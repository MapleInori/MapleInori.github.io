# C# 基础

## 复杂数据类型

「复杂数据类型」不是 C# 官方严格的分类，而是学习时相对于 `int`、`float`、`bool` 等基础类型的教学统称。它们通常用于表示一组数据、状态或一个自定义事物。

- `enum`：一组有名字的状态或选项，例如玩家职业、场景状态。
- 数组：一组相同类型的数据，例如 `int[] scores`。
- `struct`：由多个相关字段组成的自定义类型，例如包含姓名、血量和攻击力的玩家。
- `class`：更完整的自定义类型。

> C# 正式的类型分类是值类型和引用类型；「复杂数据类型」只是方便学习的叫法。

## 一、枚举

### 1. 枚举的定义与声明

枚举（`enum`）是一组**有名字的整数常量**，默认底层类型为 `int`。它适合表示数量固定、彼此互斥的状态或类型，例如玩家职业、怪物类型、场景状态。

```csharp
enum MonsterType
{
    Normal,
    Boss,
}
```

- 声明枚举是在定义一个新类型；声明枚举变量才是在使用这个类型。
- 枚举通常声明在命名空间中，也可以声明在 `class` 或 `struct` 中；不能写在函数内部。
- 自己写代码时统一使用有意义的帕斯卡命名即可，例如 `MonsterType`。

### 2. 枚举项的默认值与自定义值

枚举项默认从 `0` 开始，后面的项依次加 `1`：

```csharp
enum PlayerType
{
    Main,  // 0
    Other, // 1
}
```

也可以手动指定值；后续未指定的项从前一项继续递增：

```csharp
enum ItemType
{
    Potion = 5,
    Weapon,       // 6
    Armor = 100,
    Material,     // 101
}
```

### 3. 枚举变量的使用

```csharp
PlayerType playerType = PlayerType.Other;

if (playerType == PlayerType.Main)
{
    Console.WriteLine("主玩家逻辑");
}
```

枚举变量保存的是一个整数值，但用枚举项来判断和赋值，可读性比直接写 `0`、`1` 更好。

### 4. 枚举与 `int`、`string` 的转换

```csharp
PlayerType playerType = PlayerType.Other;

int number = (int)playerType;                     // 枚举 -> int
playerType = (PlayerType)0;                       // int -> 枚举，必须显式转换

string text = playerType.ToString();              // 枚举 -> string
playerType = Enum.Parse<PlayerType>("Other");    // string -> 枚举
```

注意：把整数强转为枚举时，编译器不会确认这个数是否有对应的枚举项；例如 `(PlayerType)99` 可以通过编译。因此用户输入的数字需要额外校验。

### 5. 枚举配合 `switch`

当一个枚举有多个明确分支时，`switch` 比连续的 `if` / `else if` 更适合：

```csharp
switch (monsterType)
{
    case MonsterType.Normal:
        Console.WriteLine("普通怪物逻辑");
        break;
    case MonsterType.Boss:
        Console.WriteLine("Boss 逻辑");
        break;
    default:
        Console.WriteLine("未知怪物类型");
        break;
}
```

- 每个非空 `case` 都要用 `break`、`return` 或 `throw` 等方式结束；C# 不允许它直接落入下一个非空 `case`。
- `default` 可以处理未定义的枚举值，尤其适合处理外部输入转换后的结果。

### 6. 枚举的使用场景

- 游戏状态：待机、行走、跳跃。
- 对象类型：普通怪、Boss、道具类别。
- 选项或配置：性别、职业、杯型。

### 7. 控制台输入与枚举校验

实际写代码时，`int.Parse` 遇到非数字会直接抛异常；用 `TryParse` 可以把「不是数字」和「数字不在枚举范围内」都显式处理：

```csharp
Console.Write("请选择怪物类型（0 普通怪，1 Boss）：");

if (int.TryParse(Console.ReadLine(), out int input) &&
    Enum.IsDefined(typeof(MonsterType), input))
{
    MonsterType monsterType = (MonsterType)input;
    Console.WriteLine($"你选择了：{monsterType}");
}
else
{
    Console.WriteLine("请输入 0 或 1。");
}
```

## 二、数组

### 1. 一维数组的声明与初始化

数组用来存储一组相同类型的数据，例如成绩、玩家或怪物。`int[]` 表示元素类型为 `int` 的一维数组，数组自身是引用类型。

```csharp
int[] scores;                        // 只声明局部变量，还不能读取它
scores = new int[3];                  // 创建 3 个元素，默认都是 0

int[] a = new int[3] { 80, 90, 100 }; // 长度与初始化元素个数必须匹配
int[] b = new int[] { 80, 90, 100 };  // 根据内容确定长度
int[] c = { 80, 90, 100 };            // 声明时的简写
```

- 类型后的 `[]` 表示数组类型，`new int[3]` 中的 `3` 表示长度。
- 只指定长度时，各元素取类型的默认值：数值是 `0`，`bool` 是 `false`，引用类型是 `null`。
- `new string[3]` 创建的是三个初始值为 `null` 的元素，不是三个空字符串；类数组也不会自动创建每个类实例。
- 声明之后重新赋值要写 `scores = new int[] { 1, 2, 3 };`，不能单独写 `scores = { 1, 2, 3 };`。
- 创建数组时长度可以来自变量，但某个数组对象创建后，长度就不能改变。

### 2. 数组的长度、索引与遍历

```csharp
int[] scores = { 80, 90, 100 };
Console.WriteLine(scores.Length); // 3，元素总数
Console.WriteLine(scores[0]);     // 80，第一个元素
scores[1] = 95;                   // 修改第二个元素

for (int i = 0; i < scores.Length; i++)
{
    Console.WriteLine($"第{i + 1}个成绩：{scores[i]}");
}
```

下标从 `0` 开始，最后一个是 `Length - 1`。遍历写 `i < scores.Length`，不是 `i <= scores.Length`；界面给用户看的序号可以用 `i + 1`。

只读取元素时，也可以用 `foreach`：

```csharp
foreach (int score in scores)
{
    Console.WriteLine(score);
}
```

这里的循环变量不是数组元素的可写别名，不能给 `score` 赋值来修改原数组。需要按下标修改、交换或记录位置时，用 `for` 更直接。

### 3. 数组元素的增、删、查、改

#### 修改与查找

修改直接使用 `array[index] = value`。不知道目标下标时，可以顺序查找：

```csharp
int[] numbers = { 3, 7, 3, 9 };
int target = 3;
int foundIndex = -1;
for (int i = 0; i < numbers.Length; i++)
{
    if (numbers[i] == target)
    {
        foundIndex = i;
        break;
    }
}
Console.WriteLine(foundIndex); // 0；找不到时保持 -1
```

`break` 表示找到第一个就结束；要找全部匹配项，就在循环中逐个记录或输出。对于这里没有顺序条件的数组，最坏要检查所有元素；二分查找则需要先满足有序等条件。

#### 追加一个元素

示例用「创建新数组，再搬数据」增加长度：

```csharp
int[] numbers = { 1, 2, 3 };
int[] expanded = new int[numbers.Length + 1];
for (int i = 0; i < numbers.Length; i++)
{
    expanded[i] = numbers[i];
}
expanded[expanded.Length - 1] = 99;
numbers = expanded; // [1, 2, 3, 99]
```

原数组没有变长，是变量改为引用新数组。向中间插入也一样：插入点前的数据原位复制，插入点后的数据向后移一位。

#### 删除指定位置

示例通过缩短数组删除末尾元素；删除中间元素时，还要跳过待删除项，把后面的数据前移：

```csharp
int[] numbers = { 10, 20, 30, 40 };
int removeIndex = 1;
if (removeIndex < 0 || removeIndex >= numbers.Length)
{
    throw new ArgumentOutOfRangeException(nameof(removeIndex));
}

int[] reduced = new int[numbers.Length - 1];
for (int i = 0; i < reduced.Length; i++)
{
    int sourceIndex = i < removeIndex ? i : i + 1;
    reduced[i] = numbers[sourceIndex];
}
numbers = reduced; // [10, 30, 40]
```

把元素改成 `0` 或 `null` 只是修改值，不会减少数组长度，也不会自动移动后面的元素。

常用方法有 `Array.IndexOf`（查找）、`Array.Copy`（复制）、`Array.Resize(ref array, newLength)`（调整变量引用的数组长度）。`Array.Resize` 改变长度时同样创建新数组并复制数据，旧数组的其它引用不会自动改变；它用于一维数组。

### 4. 数组的常见问题

#### `null`、空数组与越界

```csharp
int[] missing = null;        // 没有数组对象
int[] empty = new int[0];    // 有数组对象，但没有元素
int[] numbers = new int[3];  // 有三个值为 0 的元素
```

- `missing.Length` 会产生空引用异常；`empty.Length` 是 `0`。
- 访问负下标、`array[Length]`，或访问空数组的 `array[0]` 都会越界。
- 用第一个元素初始化最大值、最小值，或者除以长度前，要先确认数组不为 `null` 且长度大于 `0`。
- `Length` 是元素数量，不是非零值的数量，也不是占用的字节数。

#### 赋值与复制

```csharp
int[] first = { 1, 2, 3 };
int[] second = first;
second[0] = 99;
Console.WriteLine(first[0]); // 99：引用同一个数组

int[] copy = (int[])first.Clone();
copy[0] = 10;
Console.WriteLine(first[0]); // 仍是 99
```

`Clone()` 复制数组本身；如果元素是类对象或其它数组，复制的仍是元素中的引用，不会递归深拷贝对象。结构体元素中的引用字段同样可能共享数据。

### 5. 二维数组

#### 声明与初始化

二维数组用两个下标定位元素，通常把第一维约定为行、第二维约定为列，适合矩阵、棋盘和格子地图。

```csharp
int[,] emptyMap = new int[2, 3]; // 2 行 3 列，共 6 个元素
int[,] map =
{
    { 1, 2, 3 },
    { 4, 5, 6 },
};
Console.WriteLine(map[0, 1]); // 第 0 行、第 1 列：2
map[1, 2] = 99;
```

也可以写 `new int[,] { { 1, 2, 3 }, { 4, 5, 6 } }`。每行列数必须相同；这里是 `map[row, column]`，不是交错数组的 `map[row][column]`。

#### 维度长度与遍历

```csharp
int rows = map.GetLength(0);    // 2：第 0 维的长度
int columns = map.GetLength(1); // 3：第 1 维的长度
Console.WriteLine(map.Length); // 6：所有元素的总数
Console.WriteLine(map.Rank);   // 2：维度数量

for (int row = 0; row < rows; row++)
{
    for (int column = 0; column < columns; column++)
    {
        Console.Write(map[row, column] + " ");
    }
    Console.WriteLine(); // 每完成一行再换行
}
```

`GetLength(0)` 里的 `0` 是维度编号，不是第几行。行、列分别检查边界，不能把 `Length` 当作行数来遍历。

游戏里 `x` 常表示列、`y` 表示行，所以采用行列约定时应访问 `map[y, x]`。也可以采用别的约定，但整份代码要统一。

#### 增删与查找

二维数组也不能原地改变行列数。示例给地图末尾增加一行的思路是：

```csharp
int rows = map.GetLength(0);
int columns = map.GetLength(1);
int[,] expanded = new int[rows + 1, columns];
for (int row = 0; row < rows; row++)
{
    for (int column = 0; column < columns; column++)
    {
        expanded[row, column] = map[row, column];
    }
}
map = expanded; // 新增行的元素默认是 0
```

删除某行就创建少一行的新数组，复制时跳过目标行；删除某列则跳过目标列。把一个格子清零不会让矩形数组少一个元素。

查找时用双层循环，命中后同时记录行、列。如果只找第一次匹配，注意内层 `break` 只退出内层循环，外层也需要根据找到的标记退出；写成函数时可以直接 `return`。

### 6. 交错数组

交错数组是「数组的数组」。外层的每个元素是一个数组引用，所以每一行可以有不同长度，也可能尚未初始化。

```csharp
int[][] groups = new int[3][]; // 仅创建外层数组，三行暂时都是 null
groups[0] = new int[] { 1, 2, 3 };
groups[1] = new int[] { 4, 5 };
groups[2] = new int[0];

// 也可以一次初始化
int[][] other =
{
    new int[] { 1, 2, 3 },
    new int[] { 4, 5 },
    new int[] { 6 },
};

Console.WriteLine(groups.Length);    // 3：外层元素数，按行理解
Console.WriteLine(groups[0].Length); // 3：第 0 行的元素数
Console.WriteLine(groups[1][0]);     // 4
groups[1][0] = 99;
```

遍历时，内层使用**当前行**的长度，先处理可能为空的行：

```csharp
for (int row = 0; row < groups.Length; row++)
{
    if (groups[row] == null)
    {
        continue;
    }
    for (int column = 0; column < groups[row].Length; column++)
    {
        Console.Write(groups[row][column] + " ");
    }
    Console.WriteLine();
}
```

- `groups.Length` 只计算外层元素，不是所有行的元素总和；总数需要累加非空行的 `Length`。
- `groups.Rank` 是 `1`，因为外层本身是一维数组；不能用 `groups.GetLength(1)` 获取列数。
- 增删整行时调整外层数组；增删某一行的元素时调整该行数组，例如 `Array.Resize(ref groups[1], 4)`。
- 复制外层数组仍会共享内层数组。需要独立的每一行时，要逐行复制；如果行内又有引用类型元素，还要按需要继续复制。

| 对比项               | 二维数组`int[,]`     | 交错数组`int[][]`      |
| -------------------- | ---------------------- | ------------------------ |
| 形状                 | 行列组成的矩形         | 每行长度可以不同         |
| 访问                 | `array[row, column]` | `array[row][column]`   |
| 创建                 | 一次指定行列数         | 外层创建后，还要创建各行 |
| 行是否可能为`null` | 不存在单独的行数组引用 | 可以                     |
| 常见用途             | 棋盘、矩阵、规则网格   | 每组数量不同的数据       |

### 7. 细节

#### 数组反转

第 `i` 个元素与第 `Length - 1 - i` 个元素交换，只交换前半段：

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };
for (int i = 0; i < numbers.Length / 2; i++)
{
    int opposite = numbers.Length - 1 - i;
    int temp = numbers[i];
    numbers[i] = numbers[opposite];
    numbers[opposite] = temp;
}
// [5, 4, 3, 2, 1]
```

遍历整个长度会把交换结果再换回来；奇数长度中间那个元素不需要动。反转只是倒转现有顺序，不等于排序。

#### 一维下标与二维行列

把一维数组按每行 `columns` 个元素输出时：行号是 `index / columns`，列号是 `index % columns`；反向计算下标是 `row * columns + column`。

把 25 个符号按每行 5 个打印，可以在输出后判断 `(i + 1) % 5 == 0` 再换行；如果在输出前换行，要排除 `i == 0`，否则开头会多一个空行。

#### 对角线、区域与极值位置

- `n × n` 方阵的主对角线满足 `row == column`，副对角线满足 `row + column == n - 1`。
- 两条对角线求和时使用 `||` 合并条件，奇数方阵的中心只算一次；分两次累加则要去重。
- 「右上四分之一区域」与「主对角线上方」不同：前者用行列范围判断，后者用 `column > row` 判断。
- 找二维数组最大值时，保存 `maxRow`、`maxColumn`，通过 `array[maxRow, maxColumn]` 读取值；先保证数组不为空。

#### 先记录，再批量修改

二维练习要求：原数组某个位置是 `1`，就把它所在的整行、整列都改成 `1`。不能遇到一个 `1` 就立即修改，因为新增的 `1` 会被后续遍历误认为原始条件，造成继续扩散。

```csharp
static void MarkRowsAndColumns(int[,] array)
{
    if (array == null)
    {
        throw new ArgumentNullException(nameof(array));
    }

    int rows = array.GetLength(0);
    int columns = array.GetLength(1);
    bool[] markedRows = new bool[rows];
    bool[] markedColumns = new bool[columns];

    for (int row = 0; row < rows; row++)
    {
        for (int column = 0; column < columns; column++)
        {
            if (array[row, column] == 1)
            {
                markedRows[row] = true;
                markedColumns[column] = true;
            }
        }
    }

    for (int row = 0; row < rows; row++)
    {
        for (int column = 0; column < columns; column++)
        {
            if (markedRows[row] || markedColumns[column])
            {
                array[row, column] = 1;
            }
        }
    }
}
```

「先收集原始条件，再应用修改」也适合其它批量更新场景。

## 三、值类型、引用类型与 `string`

### 1. 值类型与引用类型

- 值类型：赋值时复制数据。
- 引用类型：赋值后指向同一份数据。
- 栈、堆与 `new`。

#### 数据在内存中的存储

可以先把内存理解为两块：

- **栈（Stack）**：保存当前函数的局部数据、参数和调用信息；函数结束后，这一层的数据会自动离开作用域。
- **堆（Heap）**：保存通过 `new` 创建的对象、数组等引用对象；当没有任何引用能访问某个对象时，垃圾回收器（GC）会在合适的时机回收它。

> 并非所有值类型都一定在栈上、所有引用类型都一定在堆上：例如，结构体字段会直接存放在其所属对象中。关键是区分「变量里保存的是数据本身，还是对象的位置」。

**值类型**（如 `int`、`bool`、`char`、`struct`）的变量直接保存数据。赋值时会复制一份：

```csharp
int a = 10;
int b = a;
b = 20;

// a 是 10，b 是 20
```

```text
栈
┌────────┐
│ a = 10 │
│ b = 20 │
└────────┘
```

**引用类型**（如数组、`string`、`class`）的变量保存的是对象的引用，可以把它理解成对象的地址。对象本身在堆中；赋值时复制的是引用，所以两个变量会指向同一个对象：

```csharp
int[] arr1 = { 1, 2, 3 };
int[] arr2 = arr1;
arr2[0] = 99;

// arr1[0] 也是 99
```

```text
栈                         堆
┌──────────────┐           ┌──────────────┐
│ arr1 ────────┼──────────►│ int[]        │
│ arr2 ────────┼──────────►│ [99, 2, 3]   │
└──────────────┘           └──────────────┘
```

`new` 的作用是创建一个新的对象。例如 `arr2 = new int[] { 4, 5, 6 };` 后，`arr2` 会改为指向新数组，原来的 `arr1` 不受影响。

### 2. 值类型与引用类型的赋值和传参

### 3. 特殊的引用类型 `string`

`string` 是引用类型，但字符串对象创建后不能修改。重新赋值并不是修改原字符串，而是让变量指向一个新的字符串对象：

```csharp
string str1 = "abc";
string str2 = str1;
str2 = "def";

// str1 仍是 "abc"，str2 是 "def"
```

因此，`string` 在重新赋值时看起来像值类型；但它保存的仍是引用。频繁使用 `+` 拼接字符串会不断创建新对象，产生等待 GC 回收的旧字符串。

## 四、函数

### 1. 函数的声明

函数是有名字的代码块，调用函数名就能执行里面的逻辑。在 C# 中，类和结构体里的函数通常称为「方法」。

示例采用传统的 `Program` / `Main` 结构：方法写在 `class` 中，与 `Main` 平级。以下方法定义示例都按这个结构编写，调用语句放在 `Main` 中。

```csharp
class Program
{
    static int Sum(int a, int b)
    {
        return a + b;
    }

    static void Main(string[] args)
    {
        int result = Sum(3, 5);
        Console.WriteLine(result); // 8
    }
}
```

- `static`：静态方法，可在这里直接调用，不需要先创建 `Program` 对象。它不是所有方法都必须有的关键字。
- `int`：返回类型；没有返回值时写 `void`。
- `Sum`：函数名，使用帕斯卡命名法。
- `int a, int b`：参数列表，用逗号分隔；参数名使用驼峰命名法。
- 花括号内是函数体，`return` 把结果交给调用者。

函数声明的先后顺序不影响调用，不需要为了先调用而把定义写在前面。

### 2. 函数的四种基本形式

```csharp
// 无参无返回值
static void SayHello()
{
    Console.WriteLine("你好");
}

// 有参无返回值
static void SayName(string name)
{
    Console.WriteLine($"你的名字是：{name}");
}

// 无参有返回值
static string GetName()
{
    return "MapleInori";
}

// 有参有返回值
static int Sum(int a, int b)
{
    return a + b;
}
```

调用时，即使没有参数也要写括号：

```csharp
SayHello();
SayName("MapleInori");
string name = GetName();
Console.WriteLine(Sum(3, 5));
```

### 3. 参数与返回值

#### 形参与实参

声明函数时的参数是「形参」，调用时传进去的是「实参」。实参可以是变量、常量、表达式，也可以是另一个函数的返回值，只要类型能匹配：

```csharp
string name = "MapleInori";
SayName(name);
SayName("MapleInori");
SayName(GetName()); // 先执行 GetName，再把结果传给 SayName
Console.WriteLine(Sum(1 + 2, 4)); // 7
```

形参和函数内的局部变量只在自己的作用域内使用；调用者的变量和形参即使同名，也不是同一个变量。

#### 接收返回值

有返回值的函数可以把结果存进变量，也可以直接用于表达式。单独调用也会执行函数，只是丢弃返回值。

```csharp
int result = Sum(3, 5);
Console.WriteLine(Sum(3, 5));
Sum(3, 5); // 执行了，但没有使用结果
```

非 `void` 方法不能正常执行到结尾却没有返回值：每条能够正常结束的路径都要返回与声明类型兼容的值。

#### `return` 提前结束

`return` 结束的是整个函数，`break` 只退出当前循环或 `switch`，`continue` 只跳过当前这轮循环。

```csharp
static void Speak(string text)
{
    if (string.IsNullOrEmpty(text))
    {
        return; // void 方法也能用 return，只是不带值
    }

    Console.WriteLine(text);
}
```

先排除不满足条件的情况再处理正常逻辑，可以减少 `if` 嵌套。比较大小也可以直接返回三元表达式：

```csharp
static int GetMax(int a, int b)
{
    return a > b ? a : b;
}
```

#### 返回多个结果

示例使用数组打包多个结果；函数仍然只返回一个数组，调用者需要知道每个下标的含义。

```csharp
static double[] CalcCircle(double radius)
{
    return new double[]
    {
        Math.PI * radius * radius, // [0] 面积
        2 * Math.PI * radius,      // [1] 周长
    };
}

// 调用
double[] result = CalcCircle(3);
Console.WriteLine($"面积：{result[0]}，周长：{result[1]}");
```

后续也可以用 `out`、结构体或元组返回多个结果。结果多时，用有名字的字段比约定数组下标更方便查阅。

#### 默认传参：复制值，也复制引用

普通参数默认按值传递。传值类型会复制数据，传引用类型会复制引用。

```csharp
static void ChangeValue(int value)
{
    value = 3;
}

static void ChangeArrayValue(int[] arr)
{
    arr[0] = 99;
}

static void ChangeArray(int[] arr)
{
    arr = new int[] { 10, 20, 30 };
}

// 调用
int number = 1;
ChangeValue(number);
Console.WriteLine(number); // 1

int[] numbers = { 1, 2, 3 };
ChangeArrayValue(numbers);
Console.WriteLine(numbers[0]); // 99：修改了共享的数组对象

ChangeArray(numbers);
Console.WriteLine(numbers[0]); // 仍是 99：仅给形参换了引用
```

「引用类型参数」不等于「按引用传参」。修改对象内容和修改变量所保存的引用是两件事。

### 4. `ref` 与 `out`

`ref`、`out` 都是按引用传递，让函数直接操作调用者的变量。定义参数和调用函数时都要写对应的关键字，实参必须是变量，不能传 `ref 1` 这样的常量。

| 规则                   | `ref`            | `out`                        |
| ---------------------- | ------------------ | ------------------------------ |
| 调用前是否必须赋值     | 必须               | 不必                           |
| 函数内是否可以读取原值 | 可以               | 必须先赋值才能读取             |
| 正常返回前是否必须赋值 | 不必               | 必须，所有正常返回路径都要赋值 |
| 常见用途               | 读取并修改已有数据 | 输出额外结果                   |

```csharp
static void AddOne(ref int value)
{
    value += 1;
}

static void GetValue(out int value)
{
    value = 99;
}

// 调用
int number = 1;
AddOne(ref number);
Console.WriteLine(number); // 2

GetValue(out int result);
Console.WriteLine(result); // 99
```

引用类型也能用 `ref`。这时给形参赋一个新数组，外部变量的引用也会改变：

```csharp
static void ReplaceArray(ref int[] arr)
{
    arr = new int[] { 100, 200, 300 };
}

// 调用
int[] numbers = { 1, 2, 3 };
ReplaceArray(ref numbers);
Console.WriteLine(numbers[0]); // 100
```

### 5. `params` 变长参数

调用时可以传入任意数量的同类型参数，函数内把它们当数组处理。

```csharp
static int Sum(params int[] values)
{
    int sum = 0;
    for (int i = 0; i < values.Length; i++)
    {
        sum += values[i];
    }
    return sum;
}

// 调用
Console.WriteLine(Sum());        // 0，收到长度为 0 的数组
Console.WriteLine(Sum(1, 2, 3));  // 6
int[] numbers = { 4, 5, 6 };
Console.WriteLine(Sum(numbers)); // 15，也能直接传入数组
```

- 一个方法最多一个 `params` 参数，并且必须是最后一个参数。
- 前面可以有普通参数，例如 `PrintItems(string title, params string[] items)`。
- 不传参数会得到空数组；显式传入 `null` 则是空引用，两者不同。
- 直接传已有数组时仍然共享这个数组；`params` 不会自动复制它。

### 6. 可选参数与默认值

声明时给参数一个默认值，调用时就可以省略它；传入实参时使用传入值。

```csharp
static void Speak(string name, string text = "我没什么话可说", int times = 1)
{
    for (int i = 0; i < times; i++)
    {
        Console.WriteLine($"{name}：{text}");
    }
}

// 调用
Speak("MapleInori");
Speak("MapleInori", "你好", 2);
Speak("MapleInori", times: 3); // 命名参数，省略中间的 text
```

- 必填参数放在可选参数前面。
- 默认值常用常量，例如数字、字符串、`null`、枚举项；不能用 `new int[] { 1, 2 }` 作为默认值。
- 按位置传参不能留空，例如 `Speak("MapleInori", , 3)` 不合法；需要跳过参数时使用参数名。

### 7. 函数重载

同一个类或结构体中，方法名相同，但参数列表不同，可以构成重载。适合把相近功能放在同一个名字下。

```csharp
static int CalcSum(int a, int b)
{
    return a + b;
}

static int CalcSum(int a, int b, int c) // 数量不同
{
    return a + b + c;
}

static float CalcSum(float a, float b) // 类型不同
{
    return a + b;
}

static float CalcSum(int a, float b) // 类型排列不同
{
    return a + b;
}

static float CalcSum(float a, int b)
{
    return a + b;
}
```

编译器根据实参的数量和类型选择重载。例如 `CalcSum(1, 2)` 匹配整数版本，`CalcSum(1f, 2f)` 匹配浮点版本。

- 只改变返回类型不能重载：调用时无法靠接收结果的变量类型决定选哪个方法。
- 只改变参数名、默认值或加上 `params`，不能把相同参数类型列表变成新的重载。
- 普通参数与 `ref` 参数可以构成重载；仅把 `ref` 改成 `out` 则不能。
- `1.1` 默认是 `double`，`1.1f` 才是 `float`；字面量类型会影响重载选择。

### 8. 递归函数

递归就是函数调用自己。必须有终止条件，每次调用的参数也必须向终止条件靠近。

```csharp
static void PrintNumbers(int number)
{
    if (number > 10)
    {
        return;
    }

    Console.WriteLine(number);
    PrintNumbers(number + 1);
}

// 调用
PrintNumbers(0); // 打印 0～10
```

#### 递归调用与返回

每次调用都有自己的参数和局部变量。调用下一层时，当前层等待结果；到达终止条件后，结果再逐层返回。

```csharp
static int Factorial(int number)
{
    if (number < 0)
    {
        throw new ArgumentOutOfRangeException(nameof(number));
    }
    if (number <= 1)
    {
        return 1; // 0! 和 1! 都是 1
    }

    return checked(number * Factorial(number - 1));
}
```

`Factorial(4)` 的过程：先展开为 `4 * Factorial(3)`，一直调用到 `Factorial(1)` 返回 `1`，然后逐层算出 `2`、`6`、`24`。

- 阶乘增长很快，`int` 只能容纳到 `12!`。这里用 `checked` 在溢出时抛异常，避免得到错误的整数结果。
- 每一层调用都会占用调用栈；递归太深可能造成栈溢出。简单计数通常用循环更直接。

#### 递归里的执行顺序

输出放在递归调用前是从小到大打印，放在调用后则在逐层返回时从大到小打印。计算「每天减半」这类问题时，也要明确第 `0` 天是否已经执行一次减半，防止多算一次。

还有用短路逻辑代替条件语句的写法：

```csharp
static bool PrintWithShortCircuit(int number)
{
    Console.WriteLine(number);
    return number >= 200 || PrintWithShortCircuit(number + 1);
}

// 从 1 开始调用
PrintWithShortCircuit(1);
```

当左边为 `true`，`||` 就不执行右边，递归因此终止。

## 五、结构体

### 1. 结构体的定义与使用

结构体（`struct`）是自定义的**值类型**，可以把相关的数据和操作这些数据的方法放在一起。例如学员有姓名、年龄、学号，也可以有打印个人信息的方法。

```csharp
struct Student
{
    public string name;
    public int age;
    public int number;

    public Student(string name, int age, int number)
    {
        this.name = name;
        this.age = age;
        this.number = number;
    }

    public void Speak()
    {
        Console.WriteLine($"我叫{name}，今年{age}岁，学号是{number}");
    }
}
```

结构体名使用帕斯卡命名法，通常定义在命名空间里，也可以嵌套在类或其它结构体中，不能定义在函数内部。

**定义结构体**是在创建一种类型；**声明结构体变量**是在使用这种类型，和前面的枚举一样。

以下调用语句放在 `Main` 中，结构体定义放在 `Main` 外：

```csharp
Student student = new Student("MapleInori", 18, 1);
student.Speak();
student.age = 19;
student.Speak();
```

### 2. 结构体中的成员变量与成员方法

结构体内部的成员变量称为「字段」，描述数据；成员方法描述行为。

- 字段可以是基础类型、枚举、数组、其它结构体或类。
- 实例方法通过 `student.Speak()` 调用，可以直接使用当前实例的字段。
- `static` 方法属于类型，通过类型名调用，不能直接访问某一个实例的字段。

示例中 `Speak()` 不写 `static`，是因为它需要读取当前学员的姓名、年龄；并不是结构体的方法都不能写 `static`。

结构体不能直接包含自身类型的实例字段，否则它的大小会无限递归：

```csharp
struct Node
{
    // public Node next; // 错误：自身又包含一个完整的自身
    public int value;
}
```

通过其它结构体间接包含回自身也不行。数组等引用类型字段则没有这个大小递归问题，因为字段里保存的是引用。

### 3. `public` 与 `private`

- `public`：外部代码可以访问，但也要能访问到结构体类型本身。
- `private`：只有定义该成员的类型内部能访问。
- 结构体的字段、方法不写访问修饰符时，默认是 `private`；这条规则不要和命名空间下类型默认的 `internal` 混淆。

```csharp
struct Wallet
{
    private int coins;

    public Wallet(int coins)
    {
        this.coins = coins;
    }

    public void AddCoins(int amount)
    {
        if (amount > 0)
        {
            coins += amount;
        }
    }

    public int GetCoins()
    {
        return coins;
    }
}
```

外部可以调用 `wallet.AddCoins(10)`，不能直接写 `wallet.coins = -100`。把字段设为私有，再通过方法修改，可以集中处理数据规则。

### 4. 结构体的构造函数

构造函数在创建实例时初始化数据，名字必须与结构体名相同，**不写返回类型，连 `void` 也不写**。前面的 `Student(...)` 就是构造函数，可以通过不同参数列表重载。

`this` 表示当前实例。参数与字段同名时，用它区分：

```csharp
this.age = age; // 左边是当前实例的字段，右边是传入的参数
```

只写 `age = age` 是参数赋值给自己，没有初始化字段。

#### 几种初始化方式

```csharp
// 1. 调用有参构造函数
Student first = new Student("MapleInori", 18, 1);

// 2. 只声明局部变量，再逐个赋值
Student second;
second.name = "小明";
second.age = 10;
second.number = 2;
second.Speak(); // 所有字段都赋值后，才能把它当完整实例使用

// 3. 无参 new：本例没有自定义无参构造函数，字段取默认值
Student third = new Student();
// name 为 null，age 和 number 为 0

// 4. default：取得字段均为默认值的结构体
Student fourth = default(Student);
```

数值字段默认是 `0`，`bool` 是 `false`，引用字段是 `null`；嵌套结构体的字段也按各自类型取默认值。

`Student second;` 这样的局部变量不会自动成为可读取的完整实例。未赋值前不能读取相应字段，也不能直接调用实例方法；有私有字段时，外部无法逐个赋全，通常使用构造函数更方便。

`new` 不代表一定分配到堆：结构体是值类型，是否写了 `new` 不会改变它的值类型性质。

#### 规则与语言版本

这里区分三件事：**字段声明时赋值**、**自己编写无参构造函数**，以及**构造函数有没有给所有字段赋值**。下面几个 `Player` 示例是独立的类型定义，分别对照，不放在同一个命名空间中重复声明。

**字段声明时赋值：C# 10 起支持。**

```csharp
struct Player
{
    public int hp = 100; // 实例字段初始化器

    public Player()
    {
    }
}
```

C# 10 之前，结构体不允许给实例字段写这种初始化器，通常把赋值放进有参构造函数。C# 10 起允许，但有配套要求：**只要结构体包含实例字段初始化器，就必须显式声明至少一个实例构造函数**，有参、无参都可以。不能只写 `public int hp = 100;` 就结束类型定义。

执行上例的 `new Player()` 时，先由字段初始化器把 `hp` 设为 `100`，再执行空的构造函数体。字段初始化器提供的值还可以在构造函数体中被覆盖。规则见 [Microsoft Learn：结构类型](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/struct)。

**自定义无参构造函数：C# 10 起支持，而且必须是 `public`。**

```csharp
struct Player
{
    public int hp;

    public Player()
    {
        hp = 100;
    }
}
```

「自定义构造函数必须有参数」是旧版结构体的限制，不是类的规则，也不表示旧版不能调用 `new Player()`。

C# 10 之前，可以对结构体使用默认的无参初始化，把字段设为类型默认值；只是不允许自己编写无参构造函数来改变这个行为。C# 10 起，上例中的 `new Player()` 会执行自定义构造函数，得到 `hp = 100`。版本变化见 [C# 10 官方介绍](https://devblogs.microsoft.com/dotnet/welcome-to-csharp-10/)。

**构造函数漏赋字段：C# 11 起可以自动补默认值。**

```csharp
struct Player
{
    public int hp;
    public int attack;

    public Player(int hp)
    {
        this.hp = hp;
        // 未明确给 attack 赋值
    }
}
```

这个例子在 C# 10 及以前会报错，因为构造函数正常结束时，`attack` 没有完成初始化。C# 11 起，编译器会补上它的类型默认值：

```csharp
Player player = new Player(100);
Console.WriteLine(player.hp);     // 100
Console.WriteLine(player.attack); // 0
```

可以把本例理解成编译器帮助补了 `attack = 0;`，不会根据游戏规则猜测攻击力应该是 `10`。变化见 [C# 11 自动默认初始化说明](https://devblogs.microsoft.com/dotnet/csharp-11-preview-updates/)。

字段已经有初始化器时，则使用初始化器提供的值：

```csharp
struct Player
{
    public int hp = 100;
    public int attack;

    public Player(int attack)
    {
        this.attack = attack;
    }
}
```

`new Player(20)` 得到 `hp = 100`、`attack = 20`。这个例子在 C# 10 就能成立，因为两个字段分别通过初始化器和构造函数完成了赋值，没有遗漏。

#### `new`、`default` 与只声明变量的区别

以下结构体需要 C# 10 或更高版本：

```csharp
struct Player
{
    public int hp = 100;

    public Player()
    {
        hp += 20;
    }
}
```

| 写法                           | 是否执行字段初始化器和自定义无参构造函数 | `hp` 的结果        |
| ------------------------------ | ---------------------------------------- | -------------------- |
| `new Player()`               | 先执行初始化器，再执行构造函数体         | `120`              |
| `default(Player)`            | 都不执行                                 | `0`                |
| `new Player[3]` 中的每个元素 | 都不执行                                 | `0`                |
| 局部变量`Player player;`     | 都不执行，只声明变量                     | 未赋值，不能直接读取 |

`default` 取得的是各字段的类型默认值，不是构造函数里设定的业务初始值。创建结构体数组也不会逐个执行元素的自定义无参构造函数；需要这些初始值时，要逐个赋成 `new Player()`。行为见 [结构体初始化与默认值](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/struct#struct-initialization-and-default-values)。

C# 11 自动补默认值针对的是**结构体构造函数内部**，不会让只声明的局部变量自动变得可读：

```csharp
Player player;
// Console.WriteLine(player.hp); // 仍然报错：没有给局部变量的字段赋值
```

### 5. 结构体使用注意事项

#### 赋值复制的是整个结构体的值

```csharp
Student first = new Student("小明", 18, 1);
Student second = first;
second.age = 20;
Console.WriteLine(first.age);  // 18
Console.WriteLine(second.age); // 20
```

如果结构体含有数组等引用字段，复制的是该字段的引用，**不会连数组内容一起深拷贝**：两个结构体的普通数值字段互不影响，但仍可能共享同一个数组。`string` 字段同样复制引用，不过字符串不可变，给副本的姓名重新赋值不会改变原实例的姓名。

#### 函数中修改结构体

普通参数得到的是结构体副本。想修改外部变量，可以用 `ref`，或者返回修改后的结构体并在外部接收。

```csharp
struct Fighter
{
    public string name;
    public int attack;
    public int defense;
    public int hp;

    public Fighter(string name, int attack, int defense, int hp)
    {
        this.name = name;
        this.attack = attack;
        this.defense = defense;
        this.hp = hp;
    }

    public void Attack(ref Fighter target)
    {
        int damage = Math.Max(0, attack - target.defense);
        target.hp = Math.Max(0, target.hp - damage);
        Console.WriteLine($"{name}攻击{target.name}，造成{damage}伤害，剩余血量{target.hp}");
    }
}

// Main 中调用
Fighter hero = new Fighter("雷欧奥特曼", 10, 5, 100);
Fighter boss = new Fighter("哥斯拉", 8, 4, 100);
hero.Attack(ref boss);
Console.WriteLine(boss.hp); // 94
```

如果去掉定义和调用处的 `ref`，方法内改变的是 `target` 副本，外部的 `boss.hp` 仍然是 `100`。这里需要读取原血量再修改，适合 `ref`；`out` 用来输出一个完整赋值的结果，不适合直接拿原值扣血。

#### 结构体数组

```csharp
Fighter[] monsters = new Fighter[10];
Random random = new Random();

for (int i = 0; i < monsters.Length; i++)
{
    monsters[i] = new Fighter("小怪兽" + i, random.Next(10, 30), 2, 100);
}

monsters[0].hp -= 10; // 数组元素可以直接修改

Fighter copy = monsters[0];
copy.hp -= 10;       // 这里只改副本
monsters[0] = copy;  // 需要写回，才更新数组中的数据
```

`new Fighter[10]` 已经创建了 10 个默认值元素，不是 10 个空引用，但也不会逐个调用有参构造函数。要设置名字、攻击力等数据，仍需循环初始化。

`foreach (Fighter monster in monsters)` 取得的是值的副本，不能把循环变量当作原数组元素来修改。需要更新时，这里使用 `for` 和下标更直接。

## 六、排序

排序就是把无序数据调整为升序或降序。下面的方法都直接修改传入数组中的元素。

### 1. 冒泡排序

相邻两个元素比较，顺序不对就交换。从左到右走完一轮，最大值会到最右边；再对剩下的部分重复这个过程。

以升序排列 `[5, 3, 4, 1]` 为例：

```text
第一轮：5 与 3 交换 -> 5 与 4 交换 -> 5 与 1 交换
        [3, 4, 1, 5]，5 已确定位置
第二轮：[3, 1, 4, 5]，4 已确定位置
第三轮：[1, 3, 4, 5]
```

```csharp
static void BubbleSort(int[] array, bool ascending = true)
{
    if (array == null)
    {
        throw new ArgumentNullException(nameof(array));
    }

    for (int round = 0; round < array.Length - 1; round++)
    {
        bool swapped = false;
        for (int j = 0; j < array.Length - 1 - round; j++)
        {
            bool shouldSwap = ascending
                ? array[j] > array[j + 1]
                : array[j] < array[j + 1];

            if (shouldSwap)
            {
                int temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
                swapped = true;
            }
        }

        if (!swapped)
        {
            break;
        }
    }
}
```

- 外层最多 `n - 1` 轮，剩下一个元素时不必再排。
- 内层要访问 `j + 1`，因此必须减 `1`，否则会越界。
- 每轮末尾确定一个元素的位置，下一轮再减去 `round`，不再比较已经排好的尾部。
- `swapped` 每轮重新设为 `false`。只有整轮都没有交换，才能判断当前数组已经有序。
- 交换要保存临时值；直接依次写 `array[j] = array[j + 1]` 和反向赋值，会丢失原值。

### 2. 选择排序

示例采用「每轮选最大值，放到未排序区间末尾」实现升序。内层只记录极值的**下标**，找完这一轮才交换。

```text
初始：  [5, 3, 4, 1]
第一轮：[1, 3, 4, 5]，选出 5，放到下标 3
第二轮：[1, 3, 4, 5]，选出 4，本来就在目标位置，不交换
第三轮：[1, 3, 4, 5]，选出 3，本来就在目标位置，不交换
```

```csharp
static void SelectionSort(int[] array, bool ascending = true)
{
    if (array == null)
    {
        throw new ArgumentNullException(nameof(array));
    }

    for (int round = 0; round < array.Length - 1; round++)
    {
        int end = array.Length - 1 - round;
        int index = 0;

        for (int j = 1; j <= end; j++)
        {
            bool isBetter = ascending
                ? array[j] > array[index]
                : array[j] < array[index];
            if (isBetter)
            {
                index = j;
            }
        }

        if (index != end)
        {
            int temp = array[index];
            array[index] = array[end];
            array[end] = temp;
        }
    }
}
```

- 每轮重置 `index = 0`，以未排序部分的第一个元素为起点，不能沿用上一轮的极值下标。
- 内层从 `1` 开始，范围包含 `end`；这里没有访问 `j + 1`，不要套用冒泡排序的边界。
- 交换放在内层循环外；每发现一个更大值就交换，是另一种处理过程。
- 某轮没有交换不代表整体有序。例如 `[2, 1, 3]` 第一轮的最大值已经在末尾，但前面的 `2, 1` 仍需处理。

### 3. 升序与降序

两种实现都把当前极值移到右侧，但比较条件不同：

| 排列方向 | 冒泡：相邻元素何时交换 | 选择：每轮找什么放到末尾 |
| -------- | ---------------------- | ------------------------ |
| 升序     | 左边大于右边           | 最大值                   |
| 降序     | 左边小于右边           | 最小值                   |

```csharp
int[] numbers = { 3, 7, 2, 1, 9 };
BubbleSort(numbers);
Console.WriteLine(string.Join(" ", numbers)); // 1 2 3 7 9
SelectionSort(numbers, false);
Console.WriteLine(string.Join(" ", numbers)); // 9 7 3 2 1
```

### 4. 两种排序的区别

| 对比项     | 冒泡排序                            | 选择排序                       |
| ---------- | ----------------------------------- | ------------------------------ |
| 交换时机   | 内层遇到相邻逆序就交换              | 内层结束后最多交换一次         |
| 比较次数   | 已有序时可提前结束                  | 始终比较`n(n - 1) / 2` 次    |
| 时间复杂度 | 最好`O(n)`，平均和最坏 `O(n²)` | 最好、平均和最坏都是`O(n²)` |
| 额外空间   | `O(1)`                            | `O(1)`                       |
| 稳定性     | 相等时不交换，稳定                  | 跨位置交换，不稳定             |

「稳定」指比较关键字相等的元素，排完后仍保持原先的相对顺序。比如有名字的两个相同分数学员，稳定排序不会改变他们的先后。单纯的整数数组看不出这个区别。
