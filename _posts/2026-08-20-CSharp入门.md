# C# 入门

## 一、注释与程序结构

### 1. 注释

三种写法：

```csharp
// 单行注释
/* 多行注释 */
/// <summary> 文档注释，写在函数或类上面，鼠标悬停能看到 </summary>
```

另外还有个折叠代码用的 **`#region` / `#endregion`**，成对出现：

```csharp
#region 知识点一 如何申明变量
// ...
#endregion
```

它的本质是**编辑器的预处理指令**，只在写代码时起折叠作用，编译或发布之后会被直接丢掉，对程序没有任何影响。

### 2. 程序文件的基础结构

```csharp
using System;                    // 引用命名空间

namespace Lesson2_变量           // 命名空间
{
    class Program                // 类
    {
        static void Main(string[] args)   // 主函数，程序主入口
        {
            // 目前学的内容都写在这里
        }
    }
}
```

`Main` 是程序入口，一个程序只能有一个。

## 二、变量与常量

### 3. 控制台输入语句输出语句

输出两个：

- `Console.WriteLine()` —— 打印完自动换行；不传参数就是单纯输出一个空行
- `Console.Write()` —— 打印完不换行

输入两个：

- `Console.ReadLine()` —— 能输入很多内容，**必须按回车才结束**，返回值一定是 `string`
- `Console.ReadKey()` —— 按任意一键就算输入结束；`ReadKey(true)` 传 `true` 表示**不把输入的字符回显到控制台**，取字符用 `.KeyChar`

```csharp
char c = Console.ReadKey(true).KeyChar;
```

`ReadKey(true)` 这个用法在后面做控制台游戏时会一直用到，不然玩家按的每个键都会打在屏幕上。

### 4. 变量

固定写法：`变量类型 变量名 = 初始值;`，其中 `=` 和 `;` 是死的，初始值必须和类型对得上。

一共 14 种类型，范围和占用空间必须记住：

| 分类       | 类型        | 范围 / 精度          | 字节 |
| ---------- | ----------- | -------------------- | ---- |
| 有符号整型 | `sbyte`   | -128 ~ 127           | 1    |
|            | `short`   | -32768 ~ 32767       | 2    |
|            | `int`     | 约 -21 亿 ~ 21 亿    | 4    |
|            | `long`    | 约 ±9 百万兆        | 8    |
| 无符号整型 | `byte`    | 0 ~ 255              | 1    |
|            | `ushort`  | 0 ~ 65535            | 2    |
|            | `uint`    | 0 ~ 42 亿多          | 4    |
|            | `ulong`   | 0 ~ 18 百万兆        | 8    |
| 浮点数     | `float`   | 7~8 位有效数字       | 4    |
|            | `double`  | 15~17 位有效数字     | 8    |
|            | `decimal` | 27~28 位有效数字     | 16   |
| 特殊       | `bool`    | `true` / `false` | 1    |
|            | `char`    | 单个字符，单引号     | 2    |
|            | `string`  | 一串字符，无上限     | 不定 |

几个容易错的点：

- **C# 里小数字面量默认是 `double`**，所以 `float` 必须加 `f`、`decimal` 必须加 `m`：

  ```csharp
  float f = 1.01234567890f;
  decimal de = 0.123456789012345678901234567890m;
  ```
- **有效数字从左往右第一个非 0 数开始算**，超出的部分四舍五入
- `decimal` 精度高但开销大，**不建议使用**
- 变量不能无中生有，**必须先声明才能用**
- 同类型可以一行声明多个：`int a = 1, b = 2, c = 3;`
- 声明时可以不给初始值，但**不建议，这样不安全**

### 5. 变量的本质

存储单位换算：

```
1 byte = 8 bit
1 MB = 1024 byte
1 GB = 1024 MB
1 TB = 1024 GB
```

用 `sizeof()` 可以拿到类型占用的字节数：

```csharp
int intSize = sizeof(int);      // 4
```

**`sizeof` 对 `string` 无效**，因为字符串长度是可变的、不固定。

变量的本质是二进制。为什么是二进制：数据传递只能靠电信号，而电信号只有开和关两种状态，所以用 0 和 1 表示。`bit`（位）是最小存储单位，只能表示 0 或 1；8 个 bit 组成 1 个 `byte`，所以说"一个字节 8 位"：

```
1 byte = 0000 0000
```

不同类型之所以范围不同，本质就是占的位数不同。

### 6. 变量的命名规范

四条硬规则，违反了直接编译不过：

1. 不能重名
2. 不能以数字开头
3. 不能用程序关键字
4. 不能含特殊符号（**下划线除外**）

建议部分：

- 名字要有含义，用英文表达用途，**非常不建议用汉字命名**
- **驼峰命名法**（首字母小写，后续单词首字母大写）用于变量：`myName`
- **帕斯卡命名法**（所有单词首字母大写）用于函数、类：`MyName`
- C# 严格区分大小写，`myName` 和 `MyName` 是两个不同的标识符

### 7. 常量

```csharp
const float PI = 3.1415926f;
```

两个特点，和变量正好相反：

- **必须初始化**（不能先声明后赋值）
- **不能被修改**

游戏开发里的典型用途：圆周率、角度转弧度和弧度转角度的系数、重力加速度——这类数学定理或公式性质的、参与计算但永远不变的量。如果游戏设定里某个值确定不会变（比如最大血量固定），也可以用常量。

## 三、类型转换与运算符

### 8. 转义字符

转义字符是字符串的一部分，写法是 `\` 加一个字符。

常用的四个：

| 写法   | 含义                               |
| ------ | ---------------------------------- |
| `\'` | 单引号                             |
| `\"` | 双引号                             |
| `\n` | 换行                               |
| `\\` | 反斜杠（**写文件路径必用**） |

了解即可的：`\t` 制表符、`\b` 光标退格、`\0` 空字符、`\a` 警报音。

**取消转义**：字符串前面加 `@`，里面的内容原样输出，写路径时特别省事：

```csharp
Console.WriteLine(@"C:\Users\test\file.txt");
```

### 9. 隐式转换

规则一句话：**自动转换，大范围装小范围**（高精度装低精度）。

同类内部的方向：

- 有符号：`long` → `int` → `short` → `sbyte`
- 无符号：`ulong` → `uint` → `ushort` → `byte`
- 浮点：`double` → `float`

跨类的几条要记牢：

- **整型可以隐式转浮点**，反过来不行（整数存不了小数）
- **`decimal` 不能隐式接收 `double` 和 `float`**，但可以隐式接收所有整型
- **有符号不能隐式转无符号**（可能是负数）
- 无符号转有符号要求**范围完全覆盖**：`int i = b;`（byte）合法，`int i = ui;`（uint）不合法，因为 uint 可能超出 int 上限
- **`char` 不能隐式接收其他类型**，但 `char` 可以隐式转成整型和浮点型，得到的是 **ASCII 码**
- **`string` 和 `bool` 完全不参与隐式转换**

总结成两条链：

```
double → float → 整型（有符号/无符号）→ char
decimal → 整型 → char
```

### 10. 显示转换

四种方式：

| 方式         | 写法                   | 适用                                   |
| ------------ | ---------------------- | -------------------------------------- |
| 括号强转     | `i = (int)l;`        | 数值类型之间，低精度装高精度           |
| `Parse`    | `int.Parse(str)`     | 字符串转数值，**字符串必须合法** |
| `Convert`  | `Convert.ToInt32(x)` | 数值或字符串都能接                     |
| `ToString` | `i.ToString()`       | 任意类型转字符串                       |

```csharp
char c = (char)24069;              // 强转
char c2 = Convert.ToChar(24069);   // Convert
```

最常用的场景：`Console.ReadLine()` **返回的一定是 `string`**，要参与计算必须先转：

```csharp
int shuXue = int.Parse(Console.ReadLine());
```

### 11. 异常捕获

`Parse` 的时候如果用户输入了非数字，程序会直接报错崩掉。异常捕获就是为了让程序出错时不卡死。

```csharp
try
{
    int i = int.Parse(Console.ReadLine());
}
catch (Exception e)
{
    Console.WriteLine("请输入合法数字");
}
finally
{
    // 不管出不出错最后都执行，可选，目前可以不写
}
```

- `try` 包住希望被保护的代码
- `catch` 出错时执行，`catch (Exception e)` 可以通过 `e` 拿到具体错误信息
- `finally` 可选
- **注意分号**：`try`/`catch`/`finally` 的结构本身不加分号，只有花括号内的语句才加

### 12. 算术运算符

关于 `=` 的一条核心理解：**先看右边，再看左边**。把右侧算完的结果赋给左侧变量。自己参与运算（`i = i + 1`）也遵循这一条。

**整数除法的大坑**：整数字面量默认是 `int`，两个整数相除会直接丢掉小数部分。

```csharp
float f = 1 / 2;      // 结果是 0，不是 0.5
float f2 = 1 / 2f;    // 结果是 0.5，让运算带上浮点特征
```

取余 `%` 拿到的是余数，`4 % 3` 得 1。判断奇偶、`switch` 转等级、循环里取模都靠它。

优先级：`*` `/` `%` 高于 `+` `-`；括号可以改变优先级，多层括号从最内层往外算。

复合运算符 `+=` `-=` `*=` `/=` `%=`，语义是"自己 = 自己与右侧运算"：

- 右侧是表达式会**先整体算完**：`i += 20 * 2 / 10;` 相当于 `i += 4`
- **只能进行一种运算，不能混合**：`i */-= 2;` 是非法的

自增自减：`a++` 先用再加，`++a` 先加再用；`a--` 先用再减，`--a` 先减再用。

### 13. 字符串拼接

`string` 不参与算术运算，但可以用 `+` 拼接，而且 **`+` 是唯一能用的符号**，`-` `*` `/` `%` 都不行。拼接时会自动把数字、`bool` 转成字符串接上去，`+=` 同样适用。

**核心易错点：混合表达式里 `+` 的含义，取决于从左往右先遇到什么。**

```csharp
str += 1 + 2 + 3 + 4;         // 先算成 10，再拼 → "10"
str += "" + 1 + 2 + 3 + 4;    // 开头是空字符串，逐个拼 → "1234"
str += (3 + 4);               // 括号强制先做数学运算 → "7"
```

第二种拼接方式是占位符：

```csharp
string s = string.Format("我叫{0}，今年{1}岁", name, age);
Console.WriteLine("我叫{0}，今年{1}岁", name, age);   // 打印也支持
```

占位符编号从 `0` 开始依次往后。**后面提供的内容比占位符多不会报错，比占位符少会报错。**

### 14. 条件运算符

`>` `<` `>=` `<=` `==` `!=`，结果一定是 `bool`。

- 必须"左边 运算符 右边"**成对出现**，而且**结果必须被使用**（赋值给 `bool` 或直接用于判断），单写 `a > b;` 不合法
- **优先级低于算术运算符**：`a + 3 > a - 2 + 3` 是先算两边再比较
- **不能做范围比较**：`1 < a < 6` 在 C# 里写不出来，必须拆成两个条件配合逻辑运算符
- 数值类型之间（`int`/`float`/`double`/`short`/`byte`/`uint`）可以任意混合比大小
- `char`/`string`/`bool` 只能同类型做 `==` 和 `!=`；**`char` 是例外**，它还能和数值或其他 `char` 比大小，本质是比 ASCII 码

### 15. 逻辑运算符

只作用于 `bool` 相关内容：`bool` 变量、条件表达式、逻辑表达式。

- `&&` 有假则假，同真为真
- `||` 有真则真，同假为假
- `!` 取反，可以连写 `!!true`

优先级：**`!` 最高 → `&&` 高于 `||`**；而 `&&` 和 `||` 整体**低于**算术运算符和条件运算符（`!` 是例外，所以 `!(3 > 2)` 必须加括号）。

```csharp
gameOver || isWin && health > 0    // 先算 && 再算 ||，最常见的记错点
```

**短路规则（重点）**：`||` 左边为真、`&&` 左边为假时，右边**根本不会执行**。如果右边写了带副作用的代码，那个副作用就不会发生，是很隐蔽的 bug：

```csharp
result = i > 0 || ++i >= 1;    // 左边真，右边不执行，i 不会自增
```

判断"某值在两数之间"的标准写法：`i > 1 && i < 5`。

写复杂条件时宁可多打括号，别指望记得优先级。

### 16. 位运算符

面向数值类型：先把数转成二进制，再按位对齐计算。

- `&` 按位与——有 0 则 0
- `|` 按位或——有 1 则 1
- `^` 按位异或——相同为 0，不同为 1
- `~` 按位取反——逐位取反

`~` 的结果涉及反码补码，所以 `~5` 得到 `-6` 这种"意外"值。

为什么是 `-6`：`int` 占 32 位，`5` 写成二进制是 `0000…0101`；`~` 把每一位都反过来，得到 `1111…1010`。按补码规则，最高位是 `1` 就表示负数，这个数恰好是 `-6`。记住一个万能公式：**`~x` 恒等于 `-x - 1`**，所以 `~5 = -5 - 1 = -6`，`~(-1) = 0`。

反过来，**求一个数的负数**（补码）就是「取反再加一」。以 `-5` 为例：

```
5      = 0000 0101
取反    = 1111 1010
再加 1  = 1111 1011   // 这就是 -5
```

所以 `~5` 之所以是 `-6`，正是因为它停在「取反」这一步、少了「加一」；补上那个 1（`~5 + 1`）才是 `-5`。

多个数连续位运算、没有括号时从左往右依次算；位数不齐要在左侧补 0 对齐。

移位：

```csharp
5 << 5    // 101 → 10100000 = 160，左移 n 位相当于乘 2 的 n 次方
66 >> 1   // 右移 n 位相当于整除 2 的 n 次方
```

### 17. 三目运算符

**3 个空位，2 个符号**。

```csharp
bool表达式 ? 为真返回的内容 : 为假返回的内容;
```

- 第一个空位**必须是 `bool` 结果**
- 第二、三个空位什么表达式都行，但**两者的结果类型必须一致**
- **有返回值，且必须被使用**（赋值或直接传给 `WriteLine`），不能当独立语句丢掉
- 返回值类型不限于 `string`，`int`、`bool` 都可以：

  ```csharp
  bool b = a > 1 ? a > 6 : !false;
  ```

## 四、流程控制

### 18. if 语句

`if` 是第一个能让程序产生**逻辑分支**的语句，把顺序执行变成有选择的执行。

- 条件必须是 `bool` 相关内容
- **语法部分不写分号**，`if (...)` 后面不加分号
- `if` / `if…else` / `if…else if…else` 都可以无限嵌套
- `else if` 链是"多条路"：从上往下判断，**只要满足了第一个，后面的一律不再执行**，所以**条件顺序会影响结果**
- `else` 可以省略

### 19. Switch 语句

作用和 `if` 一样是产生分支，但 **`switch` 只能判断"变量是否等于某个固定值"**。

- **`case` 后面必须是常量**：不能写范围，不能写条件运算符或逻辑运算符表达式
- `case` 数量不限；`default` 在所有 `case` 都不满足时执行，**可以省略**
- 支持 `int`、`float`、`string`、`char` 等类型，也可以用 `const` 自定义常量做 `case`
- **实际开发中一般配合枚举使用**

**贯穿（穿透）**：不写某个 `case` 的 `break`，就会顺延到下面的代码，用来让多个条件做同一件事：

```csharp
case 1:
case 3:
case 4:
    // 共用逻辑
    break;
```

`switch` 不能写范围，所以"成绩转 A~E 等级"要先 `cj /= 10` 取出十位数再 `switch`，并用 `case 10: case 9:` 贯穿合并满分和 90 分段。

### 20. while 循环

条件分支让代码**产生分支**，循环让代码**被重复执行**。

执行流程：判断条件 → 执行语句块 → 回到开头再判断。

几个要点：

- **死循环 `while(true)`**：控制台阶段会频繁用到，但**进了 Unity 基本不用**——可能因内存问题导致崩溃闪退，或者直接把程序卡死
- **忘记在循环体内改变条件变量**（比如漏写 `++i`）是最常见的死循环成因
- **嵌套时注意作用域**：在内层**声明**的变量每次进来都是全新的，和上一轮那个没有关系。用于存最终结果的变量一定要声明在循环外面
- `break` 跳出循环，`continue` 立刻回到循环开头继续下一轮。这两个是**和循环配合**的，跟 `if` 没关系（`if` 只是给它们加个条件）；`switch` 里 `break` 的作用与循环里异曲同工

### 21. do while 循环

核心区别：`while` 是**先判断再执行**，`do…while` 是不管条件真假，循环体**至少执行一次**。

```csharp
do
{
    // 至少执行一次
} while (条件);      // 注意这个分号
```

- **语法陷阱**：`} while (条件);` 结尾**必须有分号**，这是 `do…while` 独有的
- **变量必须声明在 `do` 语句块外面**，否则末尾的条件表达式访问不到
- 同样支持嵌套、`break`、`continue`

### 22. for 循环

```csharp
for (初始表达式; 条件表达式; 增量表达式)
```

**执行顺序**：第一个空位只在首次进入时执行一次；每轮进入前判断第二个空位；**循环体执行完之后才执行第三个空位**。

每个空位都很自由：

```csharp
for (int i = 0, j = 0; i < 10 && j < 0; ++i, j = j + 1)
```

三个空位都能留空，`for(;;)` 就是死循环；也可以写成 `for(; k < 10; )` 把自增放进循环体，或者省略条件靠 `break` 退出。

选择建议：**需要准确遍历某个范围内的所有数就用 `for`**；条件不确定、次数不明（比如等用户输入）更适合 `while` / `do…while`。
