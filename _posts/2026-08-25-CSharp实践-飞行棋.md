# C# 实践——飞行棋

## 一、游戏规则与控制台

### 1. 规则和操作

做一个单路线的控制台飞行棋：玩家和电脑从同一个起点出发，轮流掷骰子前进 `1～6` 格，先到达或超过终点的一方获胜。

- 地图有 `80` 格，下标为 `0～79`，起点和终点都是普通格。
- 菜单用 `W`、`S` 选择，`J` 确认；选择到边界后停住，不循环切换。
- 玩家回合和电脑回合都需要按任意键推进，电脑的点数随机生成，没有额外的决策逻辑。
- 到达终点不要求点数刚好匹配，超出时直接停在终点。
- 两个角色落在同一格时显示重合图标，没有撞回起点的规则。

| 格子           | 显示       | 落地效果                                  |
| -------------- | ---------- | ----------------------------------------- |
| 普通`Normal` | 白色`□` | 无额外变化                                |
| 炸弹`Boom`   | 红色`●` | 后退 5 格，最少退到起点                   |
| 暂停`Pause`  | 蓝色`‖` | 下次轮到自己时跳过一次掷骰子              |
| 隧道`Tunnel` | 黄色`¤` | 等概率后退 5 格、暂停一回合或交换双方位置 |

### 2. 控制台设置

```csharp
static void ConsoleInit(int w, int h)
{
    Console.CursorVisible = false;
    Console.SetWindowSize(w, h);
    Console.SetBufferSize(w, h);
}

// Main 中初始化
int w = 50;
int h = 30;
ConsoleInit(w, h);
```

这是 Windows 控制台环境下的设置。窗口和缓冲区的大小要满足终端限制；改变窗口尺寸时，也要保证缓冲区不小于窗口。

坐标原点在左上角，`x` 向右、`y` 向下。横向步长设为 `2`，纵向设为 `1`，按当前终端中图形符号的显示宽度对齐；换终端或字体后需要检查实际显示效果。

`Console.ReadKey(true).Key` 返回 `ConsoleKey`，适合菜单按键判断；`true` 表示不回显输入字符。

## 二、场景切换与菜单

### 1. 主循环分发场景

```csharp
enum E_SceneType
{
    Begin,
    Game,
    End,
}

// Main 中
E_SceneType nowSceneType = E_SceneType.Begin;
while (true)
{
    Console.Clear();
    switch (nowSceneType)
    {
        case E_SceneType.Begin:
        case E_SceneType.End:
            BeginOrEndScene(w, h, ref nowSceneType);
            break;
        case E_SceneType.Game:
            GameScene(w, h, ref nowSceneType);
            break;
    }
}
```

每次进入场景前统一清屏。开始、结束场景共用菜单函数：开始菜单进入游戏，游戏结束进入结束菜单，再选择回主菜单或退出。

`nowSceneType` 是枚举值，传参用 `ref` 才能让函数内部切换外部的当前场景。**改变场景值后，还要退出当前场景自己的循环**，主循环才能执行下一场景。

### 2. 开始和结束菜单共用函数

`BeginOrEndScene` 根据当前场景决定标题和第一个选项：

| 当前场景  | 标题     | 第一个选项 | 确认后的场景 |
| --------- | -------- | ---------- | ------------ |
| `Begin` | 飞行棋   | 开始游戏   | `Game`     |
| `End`   | 游戏结束 | 回到主菜单 | `Begin`    |

两个菜单的第二项都是「退出游戏」，执行 `Environment.Exit(0)`。`nowSelIndex` 为 `0` 或 `1`，当前选项标红，其它选项用白色。

菜单内使用 `isQuitBegin` 标记，在 `switch` 外判断并退出菜单循环。`case` 中的 `break` 只退出 `switch`；函数中没有收尾工作时，也可以用 `return` 结束整个菜单函数。

每次进入菜单都重置选择为 `0`。结束菜单没有单独保存赢家，胜负提示在进入结束场景前的游戏界面显示。

## 三、地图与数据结构

### 1. 结构体的分工

| 类型        | 关键字段                            | 负责的事情                       |
| ----------- | ----------------------------------- | -------------------------------- |
| `Vector2` | `x`、`y`                        | 保存控制台坐标，是项目自定义类型 |
| `Grid`    | `type`、`pos`                   | 保存格子类型、位置，并绘制格子   |
| `Map`     | `Grid[] grids`                    | 生成整条路线，遍历绘制地图       |
| `Player`  | `type`、`nowIndex`、`isPause` | 保存角色类型、路线下标和暂停状态 |

玩家保存的是路线下标，不是屏幕坐标。绘制时通过 `map.grids[player.nowIndex].pos` 找到对应位置，前进只需要改变下标。

```csharp
struct Vector2
{
    public int x;
    public int y;

    public Vector2(int x, int y)
    {
        this.x = x;
        this.y = y;
    }
}

enum E_Grid_Type
{
    Normal,
    Boom,
    Pause,
    Tunnel,
}

struct Grid
{
    public E_Grid_Type type;
    public Vector2 pos;

    public Grid(int x, int y, E_Grid_Type type)
    {
        pos = new Vector2(x, y);
        this.type = type;
    }
}
```

`Grid.Draw()` 先调用 `SetCursorPosition(pos.x, pos.y)`，再根据 `type` 设置颜色和输出符号。移动规则在 `RandomMove` 中处理，绘制本身不改变格子效果。

### 2. 蛇形路线的生成

游戏中使用 `Map map = new Map(14, 3, 80);`，从 `(14, 3)` 开始生成 80 个格子。

用 `indexX` 记录横向移动次数、`indexY` 记录纵向移动次数，`stepNum` 控制左右方向。地图构造函数中按这个规则设置坐标：

```csharp
int indexX = 0;
int indexY = 0;
int stepNum = 2;

for (int i = 0; i < num; i++)
{
    grids[i].pos = new Vector2(x, y);

    if (indexX == 10)
    {
        y += 1;
        ++indexY;
        if (indexY == 2)
        {
            indexX = 0;
            indexY = 0;
            stepNum = -stepNum;
        }
    }
    else
    {
        x += stepNum;
        ++indexX;
    }
}
```

先记录当前格子坐标，再计算下一个位置。`indexX == 10` 指横向已经移动了 10 次，第一排实际包含 11 个格子，不能直接理解为一排 10 格。

```text
下标 0～10： (14,3) -> (16,3) -> ... -> (34,3)
下标 11：    (34,4)
下标 12～22：(34,5) -> (32,5) -> ... -> (14,5)
下标 23：    (14,6)
下标 24：    (14,7)，继续向右
```

到达一排末尾后向下移动两次，反转横向步长，继续走下一排。地图长度、起点和横向移动次数是配套的，增加格子数量时要检查是否越过地图区的边界。

### 3. 随机格子类型

中间格子按普通格 `85%`、炸弹 `5%`、暂停 `5%`、隧道 `5%` 的概率生成。用 `Next(0, 100)` 取 `0～99`，再按区间分配类型；首尾强制设为普通格：

```csharp
int roll = random.Next(0, 100);
if (i == 0 || i == num - 1 || roll < 85)
    grids[i].type = E_Grid_Type.Normal;
else if (roll < 90)
    grids[i].type = E_Grid_Type.Boom;
else if (roll < 95)
    grids[i].type = E_Grid_Type.Pause;
else
    grids[i].type = E_Grid_Type.Tunnel;
```

这段放在地图构造函数的循环中，`random` 是循环外创建的 `Random` 实例。上述比例只针对中间格子，首尾强制普通，会让整张地图的普通格占比更高；随机生成也不保证每张地图都恰好满足比例。

### 4. 玩家数据

```csharp
enum E_PlayerType
{
    Player,
    Computer,
}

struct Player
{
    public E_PlayerType type;
    public int nowIndex;
    public bool isPause;

    public Player(int index, E_PlayerType type)
    {
        nowIndex = index;
        this.type = type;
        isPause = false;
    }
}
```

两人初始下标都是 `0`。`Player.Draw(Map mapInfo)` 按路线下标定位，玩家画青色 `★`，电脑画紫色 `▲`。

## 四、界面绘制与刷新

### 1. 红墙和信息区域

`DrawWall(w, h)` 在游戏场景刚开始时绘制固定内容：

- 横墙位于 `y = 0`、`h - 1`、`h - 6`、`h - 11`，横坐标每次加 `2`。
- 竖墙位于 `x = 0`、`w - 2`。
- 图例位于 `h - 10` 到 `h - 7`，回合提示位于 `h - 5` 到 `h - 2`。

窗口为 `50 × 30` 时，中间两道横墙在第 `19`、`24` 行，地图放在上方，下面分别留给图例和提示。

### 2. 地图先画，角色后画

每回合按以下顺序重绘：

```csharp
map.Draw();
DrawPlayer(player, computer, map);
```

地图先恢复角色离开后的格子符号，再把角色覆盖到新位置，不需要单独擦除旧棋子。固定的墙和图例不重画，也不需要每回合 `Console.Clear()`。

`DrawPlayer` 先检查双方下标是否相同：相同就画深绿色 `◎`，否则分别调用两人的 `Draw`。如果先画重合图标，再画两个角色，重合图标就会被覆盖。

### 3. 清理旧提示

新文字比旧文字短时，后半段旧字不会自动消失。`ClearInfo` 用循环在四行提示位置写空格覆盖，清理宽度取内容区的 `w - 4`：

```csharp
static void ClearInfo(int w, int h)
{
    for (int y = h - 5; y <= h - 2; y++)
    {
        Console.SetCursorPosition(2, y);
        Console.Write(new string(' ', w - 4));
    }
}
```

在回合结算前调用 `ClearInfo(w, h)`，再定位到目标行输出提示，并重新设置当前角色对应的颜色，避免沿用上次绘制留下的颜色。

> 原来的 `ClearInfo(int h)` 每行只写固定数量的空格，提示较长时可能清不干净。现在按内容区宽度清理，函数签名和调用处都要一起传入 `w`。

## 五、掷骰子与回合结算

### 1. 一局游戏的初始化与循环

`GameScene` 先画墙，生成地图，再创建玩家和电脑。每次从主菜单重新进入，都会生成新地图并重置双方状态。

```csharp
// GameScene 中，绘制并初始化 map、player、computer 后
while (true)
{
    if (PlayerRandoMove(w, h, ref player, ref computer, map, ref nowSceneType))
    {
        break;
    }
    if (PlayerRandoMove(w, h, ref computer, ref player, map, ref nowSceneType))
    {
        break;
    }
}
```

玩家和电脑复用同一个回合函数，只交换 `p` 和 `otherP` 的传入顺序。第一个调用已经结束游戏时立刻退出，不再执行电脑回合。

### 2. 回合函数的职责

`PlayerRandoMove` 负责输入、调用移动结算、重绘和切换结束场景：

```csharp
static bool PlayerRandoMove(int w, int h, ref Player p,
    ref Player otherP, Map map, ref E_SceneType nowSceneType)
{
    Console.ReadKey(true);
    bool isGameOver = RandomMove(w, h, ref p, ref otherP, map);

    map.Draw();
    DrawPlayer(p, otherP, map);

    if (isGameOver)
    {
        Console.ReadKey(true); // 留时间看胜负提示
        nowSceneType = E_SceneType.End;
    }
    return isGameOver;
}
```

`RandomMove` 返回的是「游戏是否结束」，不是「本回合有没有移动」。暂停回合没有移动，仍返回 `false`，随后轮到另一方。

### 3. 暂停、前进与终点

`RandomMove` 的结算顺序是：清提示、设角色颜色、检查暂停、掷骰子前进、判断终点、处理落点格子。

```csharp
// RandomMove 内部的核心顺序，省略界面文字
if (p.isPause)
{
    p.isPause = false;
    return false;
}

int points = random.Next(1, 7);
p.nowIndex += points;

if (p.nowIndex >= map.grids.Length - 1)
{
    p.nowIndex = map.grids.Length - 1;
    return true;
}

Grid grid = map.grids[p.nowIndex];
// 根据 grid.type 结算一次事件
```

在 `Program` 中保存一个随机数实例，掷骰子和隧道事件都复用它：

```csharp
static readonly Random random = new Random();
```

> 原来在每次 `RandomMove` 中重新创建 `Random`，这里改为复用静态字段。方法中不再单独声明随机数实例，掷骰子和事件抽取统一使用 `random`。

先检查终点，再读取格子，可以防止点数让下标超过数组长度；重绘前也要把位置限制为最后一格。

### 4. 格子事件

炸弹回退要限制下界；暂停格设置标记，等自己的下一回合再清除并跳过：

```csharp
// 炸弹
p.nowIndex = Math.Max(0, p.nowIndex - 5);

// 暂停格
p.isPause = true;
```

隧道使用 `Next(1, 91)`，把 90 种整数结果分成三份，每种事件概率都是 `1/3`：

```csharp
int eventRoll = random.Next(1, 91);
if (eventRoll <= 30)
{
    p.nowIndex = Math.Max(0, p.nowIndex - 5);
}
else if (eventRoll <= 60)
{
    p.isPause = true;
}
else
{
    int temp = p.nowIndex;
    p.nowIndex = otherP.nowIndex;
    otherP.nowIndex = temp;
}
```

交换的是双方的**位置下标**，不是整个 `Player`，因此角色类型和暂停标记仍属于各自角色。

每回合只读取并处理最初落点的格子一次。炸弹回退、隧道回退或交换位置后，不再触发新位置的格子，避免多个特殊格之间无限连锁。

### 5. `ref` 的传递要贯穿调用链

`Player` 是结构体。`GameScene` 调用 `PlayerRandoMove`、后者调用 `RandomMove` 时，都要对两名玩家使用 `ref`；中间少一层，后续修改就可能停留在副本里。

两名玩家都传 `ref`，是因为交换位置会同时修改两人。场景也用 `ref`，保证结束时能改变主循环里的场景值。

`Map` 虽然也是结构体，这里只是读取和绘制地图，按值传入即可；它的 `grids` 是数组引用，复制 `Map` 也不会深拷贝整张地图。若以后在函数里替换整个 `map.grids`，则需要重新考虑传参或返回值。

## 六、调试时检查的细节

- **路线拐弯**：重点检查下标 `10、11、12` 和 `22、23、24` 的坐标，确认转弯处没有重复或跳格。
- **终点边界**：位置 `78` 掷出 `6` 时，应停在 `79` 并获胜，不能先用 `84` 访问数组。
- **起点边界**：前五格踩炸弹或隧道后退时，不能出现负下标。
- **暂停恢复**：踩中暂停格后，下次自己的回合只清标记、不掷骰子，再下一次才恢复移动。
- **重合显示**：起点、交换后、离开重合位置时，检查 `◎` 和原格子能否正确恢复。
- **交换位置**：确认两人的下标都改变，但双方的身份和暂停状态没有被交换。
- **退出场景**：修改 `nowSceneType` 后要让内层循环返回，否则画面会停留在原场景。
- **结束提示**：胜负信息出现在游戏场景底部；按键确认后才清屏进入结束菜单，结束菜单本身没有赢家字段。
- **界面残字**：提示清理宽度要覆盖上一次输出，图形符号宽度要与终端实测一致。

## 七、代码总览

### Program.cs

完整代码放在一个文件中。创建控制台项目后，用下面的内容替换 `Program.cs`；窗口设置沿用前面的 Windows 控制台环境。

```csharp
using System;

namespace FlightChess
{
    class Program
    {
        // 地图生成、骰子和隧道事件共用随机数实例。
        internal static readonly Random random = new Random();

        static void Main(string[] args)
        {
            int w = 50;
            int h = 30;
            ConsoleInit(w, h);

            E_SceneType nowSceneType = E_SceneType.Begin;
            while (true)
            {
                // 只在进入新场景时清屏，回合刷新不清整屏。
                Console.Clear();
                switch (nowSceneType)
                {
                    case E_SceneType.Begin:
                    case E_SceneType.End:
                        BeginOrEndScene(w, h, ref nowSceneType);
                        break;
                    case E_SceneType.Game:
                        GameScene(w, h, ref nowSceneType);
                        break;
                }
            }
        }

        static void ConsoleInit(int w, int h)
        {
            Console.CursorVisible = false;
            Console.SetWindowSize(w, h);
            Console.SetBufferSize(w, h);
        }

        // 开始、结束菜单复用绘制和输入，只改变标题及第一个选项。
        static void BeginOrEndScene(int w, int h, ref E_SceneType nowSceneType)
        {
            bool isBegin = nowSceneType == E_SceneType.Begin;
            int nowSelIndex = 0;
            bool isQuitBegin = false;

            Console.ForegroundColor = ConsoleColor.White;
            Console.SetCursorPosition(isBegin ? w / 2 - 3 : w / 2 - 4, 8);
            Console.Write(isBegin ? "飞行棋" : "游戏结束");

            while (!isQuitBegin)
            {
                Console.SetCursorPosition(isBegin ? w / 2 - 4 : w / 2 - 5, 13);
                Console.ForegroundColor = nowSelIndex == 0
                    ? ConsoleColor.Red : ConsoleColor.White;
                Console.Write(isBegin ? "开始游戏" : "回到主菜单");

                Console.SetCursorPosition(w / 2 - 4, 15);
                Console.ForegroundColor = nowSelIndex == 1
                    ? ConsoleColor.Red : ConsoleColor.White;
                Console.Write("退出游戏");

                switch (Console.ReadKey(true).Key)
                {
                    case ConsoleKey.W:
                        nowSelIndex = Math.Max(0, nowSelIndex - 1);
                        break;
                    case ConsoleKey.S:
                        nowSelIndex = Math.Min(1, nowSelIndex + 1);
                        break;
                    case ConsoleKey.J:
                        if (nowSelIndex == 0)
                        {
                            nowSceneType = isBegin ? E_SceneType.Game : E_SceneType.Begin;
                            // 改变场景后，还要退出当前菜单循环。
                            isQuitBegin = true;
                        }
                        else
                        {
                            Environment.Exit(0);
                        }
                        break;
                }
            }
        }

        static void GameScene(int w, int h, ref E_SceneType nowSceneType)
        {
            DrawWall(w, h);

            // 每次进入游戏重新生成地图，并重置角色状态。
            Map map = new Map(14, 3, 80);
            Player player = new Player(0, E_PlayerType.Player);
            Player computer = new Player(0, E_PlayerType.Computer);
            map.Draw();
            DrawPlayer(player, computer, map);

            while (true)
            {
                // 同一个函数处理双方回合，参数顺序决定当前行动者。
                if (PlayerRandoMove(w, h, ref player, ref computer, map, ref nowSceneType))
                    break;
                if (PlayerRandoMove(w, h, ref computer, ref player, map, ref nowSceneType))
                    break;
            }
        }

        static bool PlayerRandoMove(int w, int h, ref Player p,
            ref Player otherP, Map map, ref E_SceneType nowSceneType)
        {
            // 电脑回合同样等待按键，只由随机数决定移动点数。
            Console.ReadKey(true);
            bool isGameOver = RandomMove(w, h, ref p, ref otherP, map);

            // 先恢复底图，再覆盖角色，顺便擦掉旧位置的角色图标。
            map.Draw();
            DrawPlayer(p, otherP, map);

            if (isGameOver)
            {
                Console.ReadKey(true); // 看完胜负提示后，再进入结束菜单。
                nowSceneType = E_SceneType.End;
            }
            return isGameOver;
        }

        static void DrawWall(int w, int h)
        {
            Console.ForegroundColor = ConsoleColor.Red;
            for (int x = 0; x < w; x += 2)
            {
                Console.SetCursorPosition(x, 0);
                Console.Write("■");
                Console.SetCursorPosition(x, h - 1);
                Console.Write("■");
                Console.SetCursorPosition(x, h - 6);
                Console.Write("■");
                Console.SetCursorPosition(x, h - 11);
                Console.Write("■");
            }
            for (int y = 0; y < h; y++)
            {
                Console.SetCursorPosition(0, y);
                Console.Write("■");
                Console.SetCursorPosition(w - 2, y);
                Console.Write("■");
            }

            // 墙内分成地图、图例、提示三个区域。
            WriteAt(2, h - 10, "□：普通格子", ConsoleColor.White);
            WriteAt(2, h - 9, "‖：暂停一回合", ConsoleColor.Blue);
            WriteAt(26, h - 9, "●：倒退5格", ConsoleColor.Red);
            WriteAt(2, h - 8, "¤：隧道，后退、暂停或交换位置", ConsoleColor.Yellow);
            WriteAt(2, h - 7, "★：玩家", ConsoleColor.Cyan);
            WriteAt(12, h - 7, "▲：电脑", ConsoleColor.Magenta);
            WriteAt(22, h - 7, "◎：双方重合", ConsoleColor.DarkGreen);
            WriteAt(2, h - 5, "按任意键开始扔骰子", ConsoleColor.White);
        }

        // 固定位置输出的小工具，每次明确设置颜色，避免受上次绘制影响。
        static void WriteAt(int x, int y, string text, ConsoleColor color)
        {
            Console.ForegroundColor = color;
            Console.SetCursorPosition(x, y);
            Console.Write(text);
        }

        static void DrawPlayer(Player player, Player computer, Map map)
        {
            if (player.nowIndex == computer.nowIndex)
            {
                Grid grid = map.grids[player.nowIndex];
                WriteAt(grid.pos.x, grid.pos.y, "◎", ConsoleColor.DarkGreen);
            }
            else
            {
                player.Draw(map);
                computer.Draw(map);
            }
        }

        static void ClearInfo(int w, int h)
        {
            // 覆盖整个提示区，避免短文字后面留下旧内容。
            for (int y = h - 5; y <= h - 2; y++)
            {
                Console.SetCursorPosition(2, y);
                Console.Write(new string(' ', w - 4));
            }
        }

        // true 代表已经产生胜者；false 代表继续下一方回合。
        static bool RandomMove(int w, int h, ref Player p, ref Player otherP, Map map)
        {
            ClearInfo(w, h);
            bool isHuman = p.type == E_PlayerType.Player;
            ConsoleColor color = isHuman ? ConsoleColor.Cyan : ConsoleColor.Magenta;
            string who = isHuman ? "你" : "电脑";
            string next = isHuman ? "电脑" : "你";

            if (p.isPause)
            {
                // 只跳过这一次，下次轮到自己时恢复掷骰子。
                p.isPause = false;
                WriteAt(2, h - 5, $"{who}暂停一回合", color);
                WriteAt(2, h - 4, $"按任意键，让{next}扔骰子", color);
                return false;
            }

            int points = random.Next(1, 7); // 1～6，上限 7 不包含。
            p.nowIndex += points;
            WriteAt(2, h - 5, $"{who}扔出的点数为：{points}", color);

            // 必须先处理终点，才能安全地用 nowIndex 访问数组。
            if (p.nowIndex >= map.grids.Length - 1)
            {
                p.nowIndex = map.grids.Length - 1;
                WriteAt(2, h - 4, isHuman
                    ? "恭喜你，你率先到达终点" : "很遗憾，电脑率先到达终点", color);
                WriteAt(2, h - 3, "按任意键结束游戏", color);
                return true;
            }

            // 只处理这次掷骰子的落点，不连锁触发后退或交换后的格子。
            Grid grid = map.grids[p.nowIndex];
            string message;
            switch (grid.type)
            {
                case E_Grid_Type.Normal:
                    message = $"{who}到达安全位置";
                    break;
                case E_Grid_Type.Boom:
                    p.nowIndex = Math.Max(0, p.nowIndex - 5);
                    message = $"{who}踩到炸弹，倒退5格";
                    break;
                case E_Grid_Type.Pause:
                    p.isPause = true;
                    message = $"{who}到达暂停点，下回合暂停";
                    break;
                case E_Grid_Type.Tunnel:
                    WriteAt(2, h - 4, $"{who}踩到时空隧道", color);
                    int eventRoll = random.Next(1, 91);
                    if (eventRoll <= 30)
                    {
                        p.nowIndex = Math.Max(0, p.nowIndex - 5);
                        message = "触发倒退5格";
                    }
                    else if (eventRoll <= 60)
                    {
                        p.isPause = true;
                        message = "触发暂停一回合";
                    }
                    else
                    {
                        // 只交换位置；身份和暂停状态仍留在各自角色上。
                        int temp = p.nowIndex;
                        p.nowIndex = otherP.nowIndex;
                        otherP.nowIndex = temp;
                        message = "双方交换位置";
                    }
                    WriteAt(2, h - 3, message, color);
                    WriteAt(2, h - 2, $"按任意键，让{next}扔骰子", color);
                    return false;
                default:
                    throw new InvalidOperationException("未知格子类型");
            }

            WriteAt(2, h - 4, message, color);
            WriteAt(2, h - 3, $"按任意键，让{next}扔骰子", color);
            return false;
        }
    }

    struct Grid
    {
        public E_Grid_Type type;
        public Vector2 pos;

        public Grid(int x, int y, E_Grid_Type type)
        {
            pos = new Vector2(x, y);
            this.type = type;
        }

        public void Draw()
        {
            Console.SetCursorPosition(pos.x, pos.y);
            switch (type)
            {
                case E_Grid_Type.Normal:
                    Console.ForegroundColor = ConsoleColor.White;
                    Console.Write("□");

                    Console.ForegroundColor = ConsoleColor.Red;
                    Console.Write("●");
                    break;
                case E_Grid_Type.Pause:
                    Console.ForegroundColor = ConsoleColor.Blue;
                    Console.Write("‖");
                    break;
                case E_Grid_Type.Tunnel:
                    Console.ForegroundColor = ConsoleColor.Yellow;
                    Console.Write("¤");
                    break;
            }
        }
    }

    struct Map
    {
        public Grid[] grids;

        public Map(int x, int y, int num)
        {
            if (num < 2)
                throw new ArgumentOutOfRangeException(nameof(num));

            grids = new Grid[num];
            int indexX = 0;
            int indexY = 0;
            int stepNum = 2;

            for (int i = 0; i < num; i++)
            {
                // 使用 100 种结果，分配 85%、5%、5%、5% 的概率。
                int roll = Program.random.Next(0, 100);
                E_Grid_Type type;
                if (i == 0 || i == num - 1 || roll < 85)
                    type = E_Grid_Type.Normal;
                else if (roll < 90)
                    type = E_Grid_Type.Boom;
                else if (roll < 95)
                    type = E_Grid_Type.Pause;
                else
                    type = E_Grid_Type.Tunnel;

                grids[i] = new Grid(x, y, type);

                // 先保存当前格子，再计算下一个坐标。
                // 横移十次后下移两次，反向继续，形成蛇形路线。
                if (indexX == 10)
                {
                    y++;
                    indexY++;
                    if (indexY == 2)
                    {
                        indexX = 0;
                        indexY = 0;
                        stepNum = -stepNum;
                    }
                }
                else
                {
                    x += stepNum;
                    indexX++;
                }
            }
        }

        public void Draw()
        {
            for (int i = 0; i < grids.Length; i++)
            {
                grids[i].Draw();
            }
        }
    }

                ? ConsoleColor.Cyan : ConsoleColor.Magenta;
            Console.Write(type == E_PlayerType.Player ? "★" : "▲");
        }
    }
```
